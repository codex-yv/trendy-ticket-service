Trendy Ticket Service — API Docs & Integration

Quick integration guide: obtain API Key & Event Token, attach payment/generate buttons, and process payments or issue tickets.

Getting Started

FastAPI-ready examples included

1) Create an account & generate API Key

  • Sign up on the dashboard (e.g., /signup).
  • After login, go to Developer / API Keys and click Generate API Key.
  • Copy your API_KEY and keep it secret. Use it in the Authorization header for server → API calls.

You can also create keys programmatically (example below).

2) Create an Event & get Event Token

  • From the dashboard, click Create Event and fill event details (name, date, capacity, price rules).
  • The server returns an event_token for the event — use it on the frontend or server when processing payments or generating tickets.
Security note: Never expose your API_KEY in frontend code. Send API_KEY from your server when creating events or generating server-to-server tokens. Frontend may use event_token which has limited scope.

Integration — Attach Payment / Generate Buttons

No input tag required — amount sourced from button data-amount

Place one or more buttons anywhere on your site using the class tt-pay-btn or tt-generate-btn. Each button should have data-amount (INR/units) and data-event attributes.

HTML (example)

// payment button (reads amount from data-amount)
<button class="btn tt-pay-btn" data-amount="500" data-event="evt_tok_XYZ">Pay ₹500</button>

<!-- generate ticket (server will create ticket without processing payment) -->
<button class="btn.ghost tt-generate-btn" data-amount="0" data-event="evt_tok_XYZ">Generate Free Ticket</button>

Integration Script (copy)

Replace YOUR_API_HOST with your backend (server-side) base URL. Put this script near the end of your page or bundle it.

Integration Script
Use this exact script in your frontend (no modifications).
Copied!
async function sendPayment() {
  const amount = document.getElementById("amount").value;
  const token = "YOUR_EVENT_TOKEN"  // Replace with your Event Token
  const key = "YOUR_API_KEY"        // Replace with your API Key

  if (!amount || amount <= 0) {
    alert("Please enter a valid amount");
    return;
  }

  try {
    const response = await fetch("https://trendyticketservices.onrender.com/payment", {
      method: "POST",
      headers: { 
        "Content-Type": "application/json",
        "Accept": "application/json"  // ✅ This tells backend to return JSON
      },
      body: JSON.stringify({
        amount: parseFloat(amount),
        payment: true,  // true if you want payment processed on our website
        token: token,
        key: key
      }),
    });

    const data = await response.json();
    
    if (data.success && data.redirect_url) {
      // Navigate to the payment page
      window.location.href = "https://trendyticketservices.onrender.com" + data.redirect_url;
    } else {
      alert("Payment request failed. Please try again.");  
      // This message appears if your event token or API key is incorrect
    }
  } catch (error) {
    console.error("Error:", error);
    alert("Payment request failed. Please try again.");
  }
}
Where amount can come from
  • Hard-coded data-amount on each button (recommended for fixed-price items).
  • Selected price option on page (read from a selected card / dropdown) and set data-amount dynamically before click.
  • Computed value (e.g., quantity × price) — programmatically set data-amount or call sendPayment with computed amount.

Security checklist

  • Do not embed API_KEY in JS served to clients.
  • Use server to call payment gateway (Razorpay) with secret keys.
  • Event token should be short-lived / scoped to a single event.
  • Use HTTPS for all endpoints.
